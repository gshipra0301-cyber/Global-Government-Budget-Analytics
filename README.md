# Global Government Budget Analytics

An interactive data analytics project for analyzing government budget trends, country-wise spending, and sector-level expenditure using Python, SQL, and Streamlit.

## Project Overview

This project analyzes historical government budget data across multiple countries and sectors. It combines Python, MySQL, SQL, statistical analysis, and Streamlit to provide interactive insights into budget allocation and spending patterns.

## Technologies Used

- Python
- SQL / MySQL
- Pandas
- NumPy
- SQLAlchemy
- Streamlit
- Plotly

## Key Features

- Country-wise government budget analysis
- Historical budget trend analysis
- Sector-wise expenditure analysis
- Statistical anomaly detection
- Correlation analysis
- Budget volatility analysis
- Interactive Streamlit dashboard
- MySQL database integration

## Project Modules

- `main_dashboard.py` — Main Streamlit dashboard
- `python_sql.py` — Loads budget data into MySQL
- `advance_query.py` — Advanced SQL analysis
- `budget_volatility.py` — Budget volatility analysis
- `correlations.py` — Sector correlation analysis
- `defense_social.py` — Defence and social spending analysis
- `forcasting_engine.py` — Budget forecasting analysis
- `outlier_det.py` — Statistical outlier detection

## Dataset

The project uses historical government budget data containing country, year, total budget, and sector-level allocation information.
